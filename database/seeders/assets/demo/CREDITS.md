Swap either file for your own photography and re-seed; paths stay the same.

## Sponsor logos

`sponsors/*.svg` are original artwork drawn for the demo, for four fictional companies, so no licence
applies. Each `.png` is rendered from its `.svg` with macOS Quick Look and cropped to 640x200. Edit the
SVG and re-render if you change one; the seeder uses the PNG, because logos can end up in PDFs where SVG
support is unreliable.
